# Verilog_SPI_Slave
SPI Slave on Verilog

## What is SPI?
SPI Stands For Serial Peripheral Interface, Which has 4 Wires: "Clock" (Not Mean the Clock, But The Square Wave Oscillating Around the Serial Data.), Master In/Slalve Out, Master Out/Slave In, Chip Select (When The Pin is Low, It Means It's Active. It Defines It's Communicating To The Specific Device.).

## What is Verilog?
Verilog is a Hardware Definition Language (HDL) Designed for FPGA or ASIC Designs. It Has Some Basic Elements: Module, Input, Output, Always, Posedge(Rising Edge), Negedge(Falling Edge).

The Verilog is Not Just a Software Code, You'd Rather Need To Think Differently. Think In Hardware, Not Merely The Code.
